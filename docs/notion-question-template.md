# 디지털 클론 질문 작성 템플릿

이 템플릿은 질문 하나를 작성하는 단위다. Notion에서 아래 블록을 복제해 사용한다.

- 선택지는 반드시 4개를 작성한다.
- 선택지 번호는 항상 `1.`부터 `4.`까지 유지한다.
- 각 항목의 제목과 코드 블록 형식을 바꾸지 않는다.
- 질문 ID는 작성하지 않는다. 추후 스크립트가 문서 순서에 따라 부여한다.
- `질문`, `선택지`, `질문 의도`, `판단축`, `선택지 의도`는 필수다.
- `상황 및 전제`, `검색 태그`, `작성 메모`는 필요 없으면 `없음`으로 작성한다.
- 선택지 의도에는 사람의 성격을 단정하지 말고, 해당 선택이 이 질문 안에서 나타내는 판단 방향만 적는다.

---

## 질문

```text
여기에 사용자에게 보여줄 질문을 작성한다.
```

## 선택지

```text
1. 첫 번째 선택지
2. 두 번째 선택지
3. 세 번째 선택지
4. 네 번째 선택지
```

## 질문 의도

```text
이 질문으로 사용자의 어떤 선택 기준이나 우선순위를 확인하려는지 1~2문장으로 작성한다.
```

## 판단축

```text
핵심: 이 질문에서 비교하는 가장 중요한 기준 A ↔ 기준 B
보조: 추가로 비교되는 기준이 있으면 작성하고, 없으면 없음
```

## 선택지 의도

```text
1. 첫 번째 선택지가 이 질문 안에서 나타내는 판단 방향
2. 두 번째 선택지가 이 질문 안에서 나타내는 판단 방향
3. 세 번째 선택지가 이 질문 안에서 나타내는 판단 방향
4. 네 번째 선택지가 이 질문 안에서 나타내는 판단 방향
```

## 상황 및 전제

```text
답변자가 같은 조건을 가정해야 한다면 작성한다. 특별한 전제가 없으면 없음.
```

## 검색 태그

```text
관련 주제를 쉼표로 구분한다. 예: 직업, 성장, 안정성, 보상
```

## 작성 메모

```text
표현 검토나 중복 확인 등 작성자끼리만 볼 메모를 적는다. 없으면 없음.
```

# 작성 예시

## 질문

```text
새로운 업무를 선택해야 한다면 무엇을 가장 우선하나요?
```

## 선택지

```text
1. 이미 익숙해서 안정적으로 수행할 수 있는 업무
2. 어렵지만 새로운 기술을 배울 수 있는 업무
3. 업무 내용보다 보상이 높은 업무
4. 책임과 부담이 적어 여유를 확보할 수 있는 업무
```

## 질문 의도

```text
새로운 업무를 선택할 때 숙련도, 성장 기회, 금전적 보상, 여유 중 어떤 기준을 우선하는지 확인한다.
```

## 판단축

```text
핵심: 안정성과 익숙함 ↔ 도전과 성장
보조: 금전적 보상 ↔ 시간과 심리적 여유
```

## 선택지 의도

```text
1. 불확실성을 줄이고 현재의 숙련도와 안정성을 우선하는 선택
2. 당장의 어려움을 감수하고 학습과 장기 성장을 우선하는 선택
3. 업무 경험보다 직접적인 금전적 보상을 우선하는 선택
4. 성장이나 보상보다 부담 감소와 개인적 여유를 우선하는 선택
```

## 상황 및 전제

```text
네 업무의 근무 장소와 고용 형태는 동일하며, 가장 큰 차이는 업무 내용과 보상 수준이라고 가정한다.
```

## 검색 태그

```text
직업, 업무 선택, 성장, 안정성, 보상, 여유
```

## 작성 메모

```text
선택지별 장단점이 한쪽으로 지나치게 유리하게 표현되지 않았는지 검토한다.
```

# 파싱 시 사용할 고정 필드명

```text
질문
선택지
질문 의도
판단축
선택지 의도
상황 및 전제
검색 태그
작성 메모
```

파싱 스크립트는 `---` 사이를 질문 하나로 보고, `##` 제목 다음의 첫 번째 코드 블록을 해당 필드 값으로 읽는다. `선택지`와 `선택지 의도`는 줄 앞의 `1.`~`4.` 번호를 기준으로 연결한다.
